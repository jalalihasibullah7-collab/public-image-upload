Pakistan Online Visa v3
========================

ویژگی جدید:
- بعد از انتخاب عکس، روی «آپلود» بزنید.
- عکس از طریق API سرور به file.io فرستاده می‌شود.
- یک لینک عمومی قابل باز شدن روی iPhone و Samsung نمایش داده می‌شود.
- دکمه «کپی لینک» دارد.
- لینک‌ها موقتی هستند (در این نسخه ۱ هفته تنظیم شده‌اند).

نکته مهم:
این پروژه فقط با باز کردن index.html به صورت فایل محلی کار نمی‌کند، چون بخش /api/upload باید روی یک سرویس Node/Vercel اجرا شود.

استقرار روی Vercel:
1. کل این پوشه را به یک repository در GitHub بفرستید.
2. پروژه را در Vercel import کنید.
3. Vercel خودش api/upload.js را به عنوان serverless function اجرا می‌کند.
